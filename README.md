# 未来のクレーム（仮）

ハンドメイド作家・フリマ出品者向けに、**出品する前に将来の購入者クレームを予測する**スマホファーストの静的Webアプリ（プロトタイプ）です。

> ⚠️ 実際の商品テストではなく、購入者の声の予測です。

## 使い方

- `index.html` をブラウザで開くだけで動きます（ビルド・サーバー・APIキー不要）。
- GitHub Pages などの静的ホスティングにそのまま置けます。
- 「サンプルで試す」の3つのボタン（ハンドメイドピアス／ハンドメイドブレスレット／中古スニーカー）でサンプルを読み込めます。読み込んだサンプル名が表示されます。
- 結果は初期表示で言われやすさ「高・中のみ」を表示します。「すべて」を選ぶと「低」も表示されます（各件数つき）。

## 入力と出力

- 入力：商品名、商品説明文、価格、発送方法、注意事項
- 出力：予測クレームのカード（言われやすさ 高/中/低 の順）
  - 言われやすさ（高/中/低）
  - 言われそうなタイミング（購入直後／到着直後／使用1週間後 など）
  - 具体的なクレーム例文
  - 予防策：説明文に足す一文・追加すべき写真・FAQ文案（コピーボタン付き）

## 仕組み（デモモード）

| ファイル | 役割 |
| --- | --- |
| `js/rules.js` | ルールベースの予測エンジン。サイズ感／色味の違い／配送遅延／梱包／価格不満／使い方の誤解／素材・アレルギー（＋中古品は商品状態）を判定 |
| `js/samples.js` | 組み込みサンプル3件と、あらかじめ用意した出力 |
| `js/generate.js` | **唯一の生成入口** `ClaimYobou.generate(input)` |
| `js/app.js` | 画面の処理 |

サンプルの入力内容がそのままなら用意済みの出力を、それ以外はルールベースで生成します。

### 本物のAI APIへの差し替え

画面は `generate()` しか呼ばないため、provider を差し替えるだけで済みます。

```js
ClaimYobou.setProvider(async (input) => {
  const res = await fetch('/api/predict', { method: 'POST', body: JSON.stringify(input) });
  return { mode: 'ai', cards: (await res.json()).cards };
});
```

カードの形：

```js
{
  category: 'size', categoryLabel: 'サイズ感',
  likelihood: '高' | '中' | '低',
  timing: '到着直後（開封時）',
  title: '思ったより小さい',
  example: '「…」',
  reason: '予測の理由（任意）',
  prevention: { sentence: '…', photos: ['…'], faq: { q: '…', a: '…' } }
}
```

※ APIキーをブラウザのコードに直接書かないでください。サーバー側（プロキシ）経由で呼び出す想定です。
